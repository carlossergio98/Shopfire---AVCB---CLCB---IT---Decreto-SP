# Fluxo 10 — Supervisão antes do Protocolo

**Objetivo:** nos primeiros meses, nenhum projeto sai sem passar por 3 portas.

```
[1] Projetista faz  →  [2] Agente revisa (Fluxo 03)  →  [3] Revisor experiente aprova  →  Protocolo
```

## Porta 2 — Revisão do agente
- Rodar o Fluxo 03 (pré-análise) com memorial + plantas.
- Só segue se **não houver nenhum item 🔴**.

## Porta 3 — Ficha para o revisor experiente
O agente gera esta ficha resumida para o revisor (seu sogro ou engenheiro parceiro) aprovar em 10 minutos:

```
FICHA DE REVISÃO — [cliente / endereço]
Enquadramento: [divisão] · [área] m² · [altura] · [CLCB / PTS / PT]  (Decreto Tab. X · IT 42 item X)
Sistemas exigidos: [lista]
Pontos que o agente marcou 🟡: [lista]
Decisões de interpretação tomadas pelo projetista: [lista]
Dúvidas abertas: [lista]
Aprovado para protocolo?  ( ) Sim  ( ) Não — ajustar: ________
Revisor: ________  Data: __/__/____
```

## Critério para reduzir a supervisão
Quando o projetista tiver **10 projetos seguidos aprovados sem Comunique-se**, a Porta 3 passa a ser por amostragem (1 a cada 3).

## Registro
Todo Comunique-se recebido vai para `PREENCHER/04-comunique-se-historico.md`, com a lição aprendida.
