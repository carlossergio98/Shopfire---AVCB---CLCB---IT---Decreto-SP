# Fluxo 03 — Pré-análise de Projeto / Memorial

**Objetivo:** pegar erros **antes do protocolo** e reduzir Comunique-se.

## Passos
1. Ler memorial e plantas enviados.
2. Conferir o **enquadramento** (Fluxo 01) com o que está no projeto.
3. Para cada sistema exigido, verificar se está **representado, dimensionado e especificado** conforme a IT.
4. Conferir simbologia (IT 04) e itens administrativos (IT 01).
5. Cruzar com `PREENCHER/04-comunique-se-historico.md` → apontar erros que **já geraram exigência** antes.
6. Cruzar com "Itens que sempre conferimos" em `PREENCHER/05-projetos-modelo.md`.
