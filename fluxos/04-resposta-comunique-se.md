# Fluxo 04 — Resposta a Comunique-se

## Passos
1. Receber o texto completo da exigência + dados do projeto.
2. Separar cada exigência em item numerado.
3. Para cada item: identificar a IT/item citado (ou o provável), confirmar no texto da norma se a exigência procede.
4. Buscar caso parecido em `PREENCHER/04-comunique-se-historico.md`.
5. Propor correção (projeto, memorial ou documento).
6. Se a exigência parecer **não proceder**, redigir justificativa técnica citando a norma — e marcar para o responsável técnico decidir (cabe recurso conforme o Decreto/IT 01).
